# Corespondența dosarului

## Răspuns către notar (structură)
1. Antet: nr. dosar succesoral, defunct (nume, CNP), data decesului, data cererii.
2. Tabel produse la data decesului: produs / tip / principal / dobândă acumulată / total; sursa: `balance_at_death`.
3. Încasări după deces: data, sumă, natura (pensie luna decesului = se cuvine; următoarele = reținute pentru retur CNPP).
4. Credite și asigurări: sold la deces, polița, stadiul daunei.
5. Retrageri de împuternicit după deces (dacă există): sumă, dată, mențiunea că mandatul a încetat (C.civ. art. 2030).
6. Mențiunea: „Sumele rămân indisponibilizate până la prezentarea certificatului de moștenitor (CGB 3.2.5 c).”
7. Semnătură: ________ (umană).

## Status către moștenitor (fără certificat)
- Ce a primit banca (tip document, dată), în ce etapă e dosarul, ce documente lipsesc, cine le poate aduce.
- Fără solduri, fără nume de alți moștenitori.

## Formulări aprobate de operator
- 2026-10-28 · Cererea de certificat suplimentar / `SUPPLEMENT_NEEDED`: o singură dată per set de lipsuri; nu o repeta la fiecare document nou dacă lista nu s-a schimbat, reminder abia după 14 zile (SC-2026-0001-02).
- 2026-10-28 · Terminologie: „bunuri” (nu „bune”); recitește textul pentru greșeli de limbă (SC-2026-0001-01).
