2. Cum treci prin pași

Din UI: /ui/ → Demo ghidat → alegi „scanate” (extractor LLM, 10–20 s/document, cere autopilotul pornit cu scripts/test-instance.sh start) sau „pre-extrase” (instant) → alegi varianta A/B → apeși „Trimite: …” o dată pentru fiecare pas.

Din terminal (pe o instanță de test, nu pe :8001 când lucrează alții — reset-ul șterge dosarul):

coordonare/bin/test-instance start                          # port 8020
curl -s -X POST localhost:8020/demo/reset
curl -s -X POST localhost:8020/demo/step/1                  # apoi 2, 3, ... 7
curl -s localhost:8020/cases/SC-2026-0001 | python3 -m json.tool   # verifici starea după fiecare pas
